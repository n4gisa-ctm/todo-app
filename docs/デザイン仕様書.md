# Todoリストアプリ デザイン仕様書

- 版数: 1.0
- 作成日: 2026-09-13
- 参考: Royal Canin Design Language (RCDL) — https://developer.royalcanin.com/

本仕様書は、Royal Canin Design Language（RCDL）の調査結果を基に、本Todoアプリに適用する
デザイントークン・コンポーネント仕様を定義する。

---

## 1. デザイン原則（RCDLからの抽出）

1. **一貫性**: 全ページで同一のトークン（色・余白・角丸・書体）のみを使用する。
2. **ブランドカラーの節度ある使用**: プライマリレッド（Brand1）は強調箇所のみに使い、
   ページ内で多用しない（RCDL: "should not be overused"）。
3. **アクセシビリティ**: 本文テキストはAA準拠のコントラストを確保する。
4. **エラー表示はオレンジ**: ブランドカラーが赤のため、エラーには赤ではなく
   オレンジ系を使用する（RCDL独自の規定を踏襲）。

## 2. カラーパレット

RCDLの実測値をそのまま採用する。

| トークン | 値 | 用途 |
|---|---|---|
| `--brand1` | `#E2001A` | プライマリ（ボタン、アクセント、ロゴ帯） |
| `--brand1-hover` | `#BD0016` | ボタンhover/active（Brand1の15%darken） |
| `--brand2` | `#808285` | セカンダリグレー（補助テキスト、アイコン枠） |
| `--brand3` | `#FFFFFF` | ベース背景（カード、ヘッダー） |
| `--brand4` | `#F6F6F6` | セクション背景（ページ地、バンド） |
| `--text` | `#444444` | 本文テキスト（AA準拠） |
| `--iconography` | `#767676` | アイコン、補助ラベル |
| `--interface` | `#D7D7D7` | 罫線、ボーダー、入力枠 |
| `--interface-dark` | `#333333` | フッター背景 |
| `--success` | `#008900` | 成功メッセージ、完了状態 |
| `--error` | `#EE8B00` | エラーメッセージ、期限超過（オレンジ） |

### グラデーション
- セクション背景に `Brand3 → Brand4`（左→右、中間点50%）のグラデーションを使用可。
- グラデーション帯と白背景を交互に配置し、隣接させない。

## 3. タイポグラフィ

- RCDL指定書体は **DIN Pro（RC TYPE）**。ライセンスフォントのため、本アプリでは
  RCDLのフォールバックスタック順序に従い代替する:
  `"RC TYPE", Roboto, Avenir, Helvetica, Arial, sans-serif`
  （Google Fonts の Roboto を読み込み、DIN Pro の代替第一候補とする）
- 見出し: Medium(500)〜Bold(700)。ページタイトルは大きく、字間はややタイト。
- 本文: Regular(400)、16px、行間1.6。
- ナビゲーション/ボタンラベル: **大文字（uppercase）+ letter-spacing 0.05em**（RCDLのナビ・ボタン様式）。

| 要素 | サイズ | ウェイト |
|---|---|---|
| ページタイトル (h1) | 32–40px | 700 |
| セクション見出し (h2) | 24px | 500 |
| カードタイトル (h3) | 18px | 500 |
| 本文 | 16px | 400 |
| 補助テキスト | 13–14px | 400 |

## 4. コンポーネント仕様

### 4.1 ヘッダー
- 白背景（Brand3）、下部にBrand1の細いアクセントラインまたは罫線（interface）。
- 中央または左にアプリロゴ（テキストロゴ、Brand1）。
- ナビリンクは uppercase、Text色 → hover時 Brand1（**0.3s linear のトランジション**）。

### 4.2 ボタン（RCDL Buttons準拠）
- **ピル型**（border-radius: 9999px / 完全な丸端）。
- Primary: 背景Brand1・文字白。hover/activeで15% darken（#BD0016）。
- Secondary(Outline): 白背景・Brand1の1px枠・Brand1文字。hoverで薄い赤背景。
- ラベルは uppercase、パディング 12px 24px 目安。
- トランジション 0.3s linear。

### 4.3 カード（Todo一覧の項目）
- 白背景（Brand3）、1px interface罫線、角丸8px、控えめな影。
- ページ地はBrand4とし、カードとのコントラストで区切る。
- カード内: タイトル(h3, Text色) / 内容(本文) / 期日（アイコン+補助テキスト）。
- 期限超過の期日はError色（オレンジ）で表示。
- 完了済みはSuccess色バッジ + タイトル打ち消し線。

### 4.4 フォーム（RCDL Forms準拠）
- ラベルは入力の上、Text色、14px。必須項目には Brand1 の「必須」表記。
- 入力欄: 白背景、1px interface枠、角丸4px、focus時にBrand1系の枠色。
- エラーメッセージはError色（オレンジ）テキスト。
- 送信=Primaryボタン、キャンセル=Outlineボタン。

### 4.5 バッジ / アラート
- 完了: Success背景の白文字 or Success文字の淡色バッジ。
- フラッシュメッセージ（保存完了等）: Success/Errorの左ボーダー付き淡色帯。

### 4.6 フッター
- InterfaceDark（#333333）背景、白/Brand4文字、小さめテキスト。

## 5. レイアウト

- 最大コンテンツ幅: 960px、中央寄せ。左右パディング16–24px。
- 余白はスペーサー基準 8px の倍数（8/16/24/32/48）。
- ブレークポイント: モバイル < 768px（1カラム化、ボタン全幅）。

## 6. インタラクション

- hover遷移は一律 **0.3s linear**（RCDL規定）。
- ボタンactive時は15% darken。
- フォーカスリングを消さない（アクセシビリティ）。

## 7. テーマカラー（v1.1追加）

設定画面からプライマリカラー（`--brand1`）を以下の10色から選択できる。
プライマリ以外のトークン（グレー系・Success・Error等）は全テーマ共通で§2の値を使用する。

| ID | 名称 | プライマリ | hover |
|---|---|---|---|
| red | レッド（既定 / RCDL Brand1） | `#E2001A` | `#BD0016`（RCDL公式値） |
| blue | ロイヤルブルー | `#0057B8` | 15% darken 自動算出 |
| teal | ティールグリーン | `#00857C` | 〃 |
| forest | フォレストグリーン | `#2E7D32` | 〃 |
| indigo | インディゴ | `#4F46E5` | 〃 |
| navy | ネイビー | `#1F4E79` | 〃 |
| purple | パープル | `#7B1FA2` | 〃 |
| rose | ローズ | `#C2185B` | 〃 |
| brown | ブラウン | `#6D4C41` | 〃 |
| slate | スレートグレー | `#37474F` | 〃 |

- hover色はRCDLの規定（15% darken）に従い、redはRCDL公式値、他はサーバー側で自動算出する。
- オレンジ・黄色系は採用しない（エラー色 `#EE8B00` との混同を避けるため。§1-4参照）。
- 淡色（アウトラインボタンのhover背景・フォーカスリング）はCSSの `color-mix()` でプライマリから導出し、全テーマで一貫させる。
- 設定画面のスウォッチは円形（直径40px前後）で表示し、選択中はチェックマークと枠線で明示する。
