# Todoリストアプリ 要件定義書

- 版数: 1.0
- 作成日: 2026-09-13
- 関連文書: [デザイン仕様書.md](./デザイン仕様書.md)

## 1. 目的

やること（Todo）を登録・管理できるWebアプリケーションを構築し、サーバー上で公開する。
データはGoogle スプレッドシートに保存し、ブラウザからいつでも確認・編集できるようにする。

## 2. システム構成

| 項目 | 採用技術 | 備考 |
|---|---|---|
| 言語 | Python 3.10+ | |
| Webフレームワーク | Flask | 軽量・学習コストが低い |
| テンプレート | Jinja2 (Flask同梱) | |
| データストア | Google スプレッドシート | gspread + サービスアカウント認証 |
| ローカル代替ストア | JSONファイル | Google認証未設定時の開発用フォールバック |
| 本番サーバー | Render (無料プラン) 等のPaaS | gunicornで起動。手順はSETUP.md参照 |

### データフロー
ブラウザ → Flask（ルーティング/バリデーション） → gspread → Google Sheets API → スプレッドシート

## 3. 機能要件

### 3.1 必須機能（ユーザー指定）

| ID | 機能 | 内容 |
|---|---|---|
| F-01 | Todo登録 | タイトル・内容・期日を入力してTodoを新規登録できる |
| F-02 | Todo編集 | 登録済みTodoのタイトル・内容・期日を変更できる |
| F-03 | 一覧表示 | 登録したTodoを一覧ページで確認できる |
| F-04 | スプレッドシート保存 | 全データはGoogle スプレッドシートに永続化される |

### 3.2 補助機能（運用上必要と判断して追加）

| ID | 機能 | 内容 |
|---|---|---|
| F-05 | 完了/未完了切替 | 一覧からワンクリックで完了状態を切り替えられる |
| F-06 | 削除 | 不要になったTodoを削除できる（確認ダイアログあり） |
| F-07 | 期限超過表示 | 期日を過ぎた未完了Todoの期日を強調表示（オレンジ） |
| F-08 | 並び順 | 一覧は「未完了→完了」「期日昇順（期日なしは末尾）」で表示 |
| F-09 | フラッシュメッセージ | 登録/更新/削除の結果を画面上部に通知 |

### 3.3 入力項目とバリデーション

| 項目 | 型 | 必須 | 制約 |
|---|---|---|---|
| タイトル | テキスト | ○ | 1〜100文字 |
| 内容 | 複数行テキスト | − | 0〜1000文字 |
| 期日 | 日付 (YYYY-MM-DD) | − | HTMLのdate入力。不正値はエラー表示 |

バリデーションエラー時は入力値を保持したままフォームを再表示し、エラーをオレンジ（デザイン仕様書 §2）で表示する。

## 4. 画面要件

| ID | 画面 | パス | 内容 |
|---|---|---|---|
| S-01 | 一覧ページ | `GET /` | Todoカードの一覧。新規登録ボタン、各カードに編集/完了/削除 |
| S-02 | 新規登録ページ | `GET/POST /todos/new` | 入力フォーム |
| S-03 | 編集ページ | `GET/POST /todos/<id>/edit` | 既存値が入ったフォーム |
| − | 完了切替 | `POST /todos/<id>/toggle` | 一覧へリダイレクト |
| − | 削除 | `POST /todos/<id>/delete` | 一覧へリダイレクト |

デザインは全画面 [デザイン仕様書.md](./デザイン仕様書.md) のトークン・コンポーネント仕様に従う。

## 5. データ仕様（スプレッドシート）

ワークシート名: `todos`（1行目はヘッダー）

| 列 | 項目 | 例 |
|---|---|---|
| A | id | UUID文字列 |
| B | title | 買い物 |
| C | content | 牛乳と卵を買う |
| D | due_date | 2026-09-20（空欄可） |
| E | status | open / done |
| F | created_at | ISO 8601 |
| G | updated_at | ISO 8601 |

- ヘッダー行・ワークシートはアプリ初回接続時に自動作成する。
- 環境変数 `SPREADSHEET_ID` で対象スプレッドシートを指定する。

## 6. 非機能要件

| 項目 | 内容 |
|---|---|
| 認証情報管理 | サービスアカウントのJSONは環境変数/Secretで渡し、リポジトリに含めない（.gitignore対象） |
| フォールバック | Google認証未設定時は `data/todos.json` に保存し、画面に開発モードである旨を表示 |
| エラー処理 | Sheets API障害時はエラーメッセージを表示し、アプリは落とさない |
| 対応ブラウザ | モダンブラウザ（Chrome/Edge/Safari/Firefox 最新） |
| レスポンシブ | 768px未満で1カラム表示 |
| 想定利用者 | 個人利用（アプリ自体のログイン機能はスコープ外） |

## 7. 公開（デプロイ）要件

- PaaS（Render想定）へgunicornでデプロイする。`render.yaml` / `Procfile` を同梱。
- 必要な環境変数:
  - `SECRET_KEY` — Flaskセッション用
  - `SPREADSHEET_ID` — 保存先スプレッドシートのID
  - `GOOGLE_CREDENTIALS_JSON` — サービスアカウントJSONの中身（文字列）
- 手順の詳細は [SETUP.md](../SETUP.md) に記載する。

## 8. スコープ外

- ユーザー登録・ログイン、複数ユーザーでのデータ分離
- 通知（メール/プッシュ）、繰り返しタスク、タグ・検索機能
