# Todoリストアプリ 要件定義書

- 版数: 1.1
- 作成日: 2026-09-13（v1.0）／ 改訂: 2026-09-13（v1.1: テーマカラー・リマインダー・繰り返しタスクを追加）
- 関連文書: [デザイン仕様書.md](./デザイン仕様書.md)

## 1. 目的

やること（Todo）を登録・管理できるWebアプリケーションを構築し、サーバー上で公開する。
データはGoogle スプレッドシートに保存し、ブラウザからいつでも確認・編集できるようにする。

## 2. システム構成

| 項目 | 採用技術 | 備考 |
|---|---|---|
| 言語 | Python 3.10+ | |
| Webフレームワーク | Flask | 軽量・学習コストが低い |
| テンプレート | Jinja2 (Flask同梱) | |
| データストア | Google スプレッドシート | gspread + サービスアカウント認証 |
| ローカル代替ストア | JSONファイル | Google認証未設定時の開発用フォールバック |
| 本番サーバー | Render (無料プラン) 等のPaaS | gunicornで起動。手順はSETUP.md参照 |

### データフロー
ブラウザ → Flask（ルーティング/バリデーション） → gspread → Google Sheets API → スプレッドシート

## 3. 機能要件

### 3.1 必須機能（ユーザー指定）

| ID | 機能 | 内容 |
|---|---|---|
| F-01 | Todo登録 | タイトル・内容・期日を入力してTodoを新規登録できる |
| F-02 | Todo編集 | 登録済みTodoのタイトル・内容・期日を変更できる |
| F-03 | 一覧表示 | 登録したTodoを一覧ページで確認できる |
| F-04 | スプレッドシート保存 | 全データはGoogle スプレッドシートに永続化される |

### 3.2 補助機能（運用上必要と判断して追加）

| ID | 機能 | 内容 |
|---|---|---|
| F-05 | 完了/未完了切替 | 一覧からワンクリックで完了状態を切り替えられる |
| F-06 | 削除 | 不要になったTodoを削除できる（確認ダイアログあり） |
| F-07 | 期限超過表示 | 期日を過ぎた未完了Todoの期日を強調表示（オレンジ） |
| F-08 | 並び順 | 一覧は「未完了→完了」「期日昇順（期日なしは末尾）」で表示 |
| F-09 | フラッシュメッセージ | 登録/更新/削除の結果を画面上部に通知 |

### 3.3 追加機能（v1.1）

| ID | 機能 | 内容 |
|---|---|---|
| F-10 | テーマカラー変更 | 設定画面で10種類のテーマカラーから選択できる。選択はスプレッドシート（settingsシート）に保存され、全ページ・全端末に反映される |
| F-11 | リマインダー通知 | 設定画面でリマインダーをオン/オフできる。オンの場合、一覧ページを開いた際に「期日が今日」または「期限超過」の未完了タスクをブラウザ通知＋画面内バナーで知らせる |
| F-12 | 繰り返しタスク | 登録・編集時に繰り返し（なし/毎週/毎月）を選択できる。繰り返し設定のあるタスクを完了にすると、次回期日の同内容タスクが自動生成される |

#### F-11 リマインダーの詳細仕様

- 通知方式は**ブラウザ通知（Web Notifications API）＋画面内バナー**とする。
  - メール・LINE・プッシュ通知等のサーバー起点の通知は、認証基盤と常時稼働が必要なため本版のスコープ外（将来拡張）。
- 通知対象: 未完了かつ「期日 ≦ 今日」のタスク。
- ブラウザ通知は1日1回まで（localStorageで通知済み日を記録し、同日の再表示を抑止）。画面内バナーは毎回表示。
- ブラウザ通知の許可が得られない場合も、画面内バナーは動作する。
- 設定でオンにした時点でブラウザに通知許可をリクエストする。

#### F-12 繰り返しタスクの詳細仕様

- 繰り返しの選択肢: なし（既定）/ 毎週 / 毎月。
- 繰り返しを設定する場合、**期日は必須**（次回期日の起点になるため）。
- 完了時の自動生成: 元タスクの「タイトル・内容・繰り返し」を引き継ぎ、期日を次回にずらした新規タスク（未完了）を作成する。元タスクは完了のまま残る。
- 次回期日の計算:
  - 毎週: 元の期日 + 7日
  - 毎月: 元の期日の翌月同日（月末超過時はその月の末日。例: 1/31 → 2/28）
  - 計算結果が過去日の場合は、今日以降になるまで間隔を繰り返し加算する（長期間放置後の完了で、即・期限超過の次回タスクが生まれるのを防ぐ）。
- 「未完了に戻す」操作では自動生成しない（完了→未完了→再完了で重複生成される可能性は許容する）。

### 3.4 入力項目とバリデーション

| 項目 | 型 | 必須 | 制約 |
|---|---|---|---|
| タイトル | テキスト | ○ | 1〜100文字 |
| 内容 | 複数行テキスト | − | 0〜1000文字 |
| 期日 | 日付 (YYYY-MM-DD) | − | HTMLのdate入力。不正値はエラー表示。**繰り返し設定時は必須** |
| 繰り返し | 選択 | − | なし / 毎週 / 毎月（既定: なし） |

バリデーションエラー時は入力値を保持したままフォームを再表示し、エラーをオレンジ（デザイン仕様書 §2）で表示する。

## 4. 画面要件

| ID | 画面 | パス | 内容 |
|---|---|---|---|
| S-01 | 一覧ページ | `GET /` | Todoカードの一覧。新規登録ボタン、各カードに編集/完了/削除 |
| S-02 | 新規登録ページ | `GET/POST /todos/new` | 入力フォーム |
| S-03 | 編集ページ | `GET/POST /todos/<id>/edit` | 既存値が入ったフォーム |
| S-04 | 設定ページ | `GET/POST /settings` | テーマカラー選択（10色スウォッチ）、リマインダーのオン/オフ |
| − | 完了切替 | `POST /todos/<id>/toggle` | 一覧へリダイレクト。繰り返しタスクなら次回タスクを自動生成 |
| − | 削除 | `POST /todos/<id>/delete` | 一覧へリダイレクト |

デザインは全画面 [デザイン仕様書.md](./デザイン仕様書.md) のトークン・コンポーネント仕様に従う。

## 5. データ仕様（スプレッドシート）

ワークシート名: `todos`（1行目はヘッダー）

| 列 | 項目 | 例 |
|---|---|---|
| A | id | UUID文字列 |
| B | title | 買い物 |
| C | content | 牛乳と卵を買う |
| D | due_date | 2026-09-20（空欄可） |
| E | status | open / done |
| F | created_at | ISO 8601 |
| G | updated_at | ISO 8601 |
| H | repeat | 空欄（なし）/ weekly / monthly ※v1.1で追加 |

- ヘッダー行・ワークシートはアプリ初回接続時に自動作成する。
- v1.0のシート（G列まで）は初回接続時にヘッダーが自動更新され、既存行のrepeatは空欄（なし）として扱う。
- 環境変数 `SPREADSHEET_ID` で対象スプレッドシートを指定する。

### 設定データ（v1.1）

ワークシート名: `settings`（key / value の2列）

| key | value | 既定値 |
|---|---|---|
| theme | テーマID（red, blue, teal, forest, indigo, navy, purple, rose, brown, slate） | red |
| reminder | on / off | off |

- テーマ10色の色定義は [デザイン仕様書.md](./デザイン仕様書.md) §7 に従う。

## 6. 非機能要件

| 項目 | 内容 |
|---|---|
| 認証情報管理 | サービスアカウントのJSONは環境変数/Secretで渡し、リポジトリに含めない（.gitignore対象） |
| フォールバック | Google認証未設定時は `data/todos.json` に保存し、画面に開発モードである旨を表示 |
| エラー処理 | Sheets API障害時はエラーメッセージを表示し、アプリは落とさない |
| 対応ブラウザ | モダンブラウザ（Chrome/Edge/Safari/Firefox 最新） |
| レスポンシブ | 768px未満で1カラム表示 |
| 想定利用者 | 個人利用（アプリ自体のログイン機能はスコープ外） |

## 7. 公開（デプロイ）要件

- PaaS（Render想定）へgunicornでデプロイする。`render.yaml` / `Procfile` を同梱。
- 必要な環境変数:
  - `SECRET_KEY` — Flaskセッション用
  - `SPREADSHEET_ID` — 保存先スプレッドシートのID
  - `GOOGLE_CREDENTIALS_JSON` — サービスアカウントJSONの中身（文字列）
- 手順の詳細は [SETUP.md](../SETUP.md) に記載する。

## 8. スコープ外

- ユーザー登録・ログイン、複数ユーザーでのデータ分離
- サーバー起点の通知（メール/LINE/Webプッシュ）— リマインダーはブラウザ通知のみ（F-11）
- タグ・検索機能
